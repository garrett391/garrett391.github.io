C&G Health Tracker

Problem
My wife and I wanted one place for meals, workouts, sleep and hydration. Everything we tried was single-user, subscription-gated, or missing half of what we cared about.
Approach
A Flask app on Azure App Service backed by Azure SQL, with five modules and a profile for each of us. Nutrition can be estimated from a plain description of a meal by way of an LLM call when the food database comes up short.
Result
In daily use by two people. I own the whole thing — schema, migrations, Bicep templates, hosting. It holds our personal health records, so it stays on a private deployment.

Shed

Play in browser
Problem
Shed — also called Palace or Karma — is easy to play and miserable to teach. Every group runs different house rules and no two groups agree on them.
Approach
A React Native app whose game engine is a pure, serialisable function: playCards(state, cards) returns new state plus events, with no React, no I/O and no mutation. Rule variants are presets over that engine rather than branches through it, so six wildly different rulesets share one code path.
Result
Runs on iOS, Android and web — playable in a browser right now. 57 engine unit tests plus a fuzz harness that plays thousands of random games across every preset, checking that cards are never created or destroyed and that every game terminates.
  • React Native
  • Expo
  • TypeScript
  • Zustand
  • Jest
  • Pure game engine
